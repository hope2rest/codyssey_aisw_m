### 경로 최적성 (최단 경로 대비)

| 조건 | A* 경로 길이 | BFS 최단 경로 | 비율 |
|------|-------------|-------------|------|
| 장애물 없음 (대각선) | 1.00x | 1.00x | 100% |

| 실패 원인 | 건수 | 비율 |
|----------|------|------|
| 동적 장애물 급격한 방향 전환 | 8 | 50% |

## 5. Fleet 운용 성능

### 5대 AMR 시뮬레이션 (1시간 운용)

| 지표 | 값 |
|------|----|
| 시간당 처리량 (tasks/hour) | 42 |
| 평균 작업 소요 시간 (s) | 85.3 |
| 로봇 가동률 | 78% |
| 교착 발생 횟수 | 3 |
| 교착 평균 해소 시간 (s) | 8.2 |
| 충전으로 인한 비가동 시간 비율 | 12% |

### Hungarian 할당 최적성

| 테스트 | 로봇 | 작업 | Hungarian 총 비용 | Greedy 총 비용 | 개선율 |
|--------|------|------|------------------|---------------|--------|
| 2x2 | 2 | 2 | 2.0 | 2.0 | 0% |
| 3x3 | 3 | 3 | 5.0 | 6.0 | 17% |
| 5x5 | 5 | 5 | 12.3 | 15.8 | 22% |
| 10x10 | 10 | 10 | 28.7 | 42.1 | 32% |

로봇/작업 수가 증가할수록 Hungarian의 최적 할당과 Greedy의 차이가 커진다. 5대 규모에서 약 20%의 총 이동 거리 절감 효과가 있다.

### 교착 탐지 정확도

| 시나리오 | 교착 수 | 탐지 성공 | 미탐지 | 오탐지 |
|---------|---------|----------|--------|--------|
| 2로봇 순환 대기 | 5 | 5 | 0 | 0 |
| 3로봇 순환 대기 | 3 | 3 | 0 | 0 |
| 교차로 병목 | 4 | 4 | 0 | 1 |
| 무교착 복잡 경로 | 0 | - | 0 | 0 |

Wait-For Graph 기반 사이클 탐지(DFS)는 순환 대기 교착을 100% 탐지한다. 교차로 병목에서 간헐적 오탐지가 발생하는데, 일시적 대기를 교착으로 판정하는 경우이다. deadlock_timeout을 적절히 설정하여 완화한다.

## 6. 핵심 알고리즘 비교 분석

### 직접 구현 vs 기존 라이브러리

| 알고리즘 | 직접 구현 | 기존 라이브러리 | 정확도 비교 | 속도 비교 |
|---------|----------|-------------|-----------|----------|
| 차동 구동 기구학 | numpy 연산 | - (고유 구현) | 기준값 | 기준값 |
| EKF 센서 퓨전 | numpy 행렬 연산 | robot_localization | 동등 (5차원) | 2~3배 느림 |
| A* 경로 계획 | heapq + dict | nav2_smac_planner | 동등 (최적성 보장) | 5~10배 느림 |
| DWA | numpy 벡터화 | nav2_dwb_controller | 유사 (파라미터 의존) | 3~5배 느림 |
| Hungarian | 행/열 감소 반복 | scipy.optimize.linear_sum_assignment | 동등 (최적) | 10~20배 느림 |
| Costmap Inflation | scipy.ndimage | nav2_costmap_2d | 동등 | 유사 |

### 직접 구현의 의의

**장점**
- 알고리즘의 내부 동작을 완전히 이해하고 디버깅할 수 있다
- ROS2 없이 단독 실행이 가능하여 테스트와 개발이 용이하다
- 파라미터 튜닝의 영향을 정확히 추적할 수 있다

**한계**
- C/C++ 기반 라이브러리 대비 속도가 느리다
- 대규모 맵(600x400)에서 A*의 계획 시간이 100ms를 초과한다
- Hungarian 알고리즘은 O(n^3)이지만 Python 루프 오버헤드로 10대 이상에서 지연이 발생한다

**결론**: 직접 구현은 알고리즘 이해와 프로토타이핑에 적합하며, 실제 배포 시에는 C++ 기반 Nav2/scipy 라이브러리를 활용하는 것이 바람직하다. 이번 프로젝트에서 직접 구현한 코드는 ROS2 환경의 동일 알고리즘과 수학적으로 동등한 결과를 산출하며, 핵심 로직의 정확성이 단위 테스트로 검증되었다.
